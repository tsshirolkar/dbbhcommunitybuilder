SUPABASE EMAIL TEMPLATES (needed so the login email contains a code)

Where: Supabase → Authentication → Email Templates.
Edit BOTH of these templates: "Confirm signup" (new members) and "Magic Link" (returning members).
Paste this as the Subject:

  Your dBBH Community Builder login code

Paste this as the message body (Source / HTML view):

  <h2>Your login code</h2>
  <p>Enter this code on the Community Builder page:</p>
  <h1 style="letter-spacing:4px">{{ .Token }}</h1>
  <p>If you did not request this, you can ignore this email.</p>

Click Save on each template.
